# U-TEED Landing Page

U-TEED의 공식 랜딩페이지입니다. React를 기반으로 제작된 현대적이고 반응형 웹사이트입니다.

## 🚀 프로젝트 개요

U-TEED는 사용자 친화적인 인터페이스와 직관적인 디자인을 제공하는 서비스입니다. 이 랜딩페이지는 서비스의 주요 기능과 특징을 소개합니다.

## ✨ 주요 기능

- **반응형 디자인**: 모든 디바이스에서 최적화된 사용자 경험
- **커스텀 폰트**: Paperlogy 폰트 패밀리 사용
- **인터랙티브 UI**: 부드러운 애니메이션과 사용자 인터랙션
- **상세 페이지**: 서비스의 세부 정보를 보여주는 전용 페이지

## 🛠️ 기술 스택

- **Frontend**: React 18
- **Styling**: CSS3
- **Build Tool**: Create React App
- **Font**: Paperlogy (Thin ~ Black)

## 📁 프로젝트 구조

```
src/
```

## 🚀 시작하기

### 사전 요구사항

- Node.js (v14 이상)
- npm 또는 yarn

### 설치 및 실행

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   ```bash
   npm start
   ```
   브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

3. **프로덕션 빌드**
   ```bash
   npm run build
   ```

## 📱 사용 가능한 스크립트

- `npm start`: 개발 모드로 앱 실행
- `npm test`: 테스트 실행
- `npm run build`: 프로덕션용 빌드 생성
- `npm run eject`: Create React App 설정 추출 (주의: 되돌릴 수 없음)

## 🎨 디자인 특징

- **Paperlogy 폰트**: 세련된 타이포그래피
- **모던 UI**: 깔끔하고 직관적인 인터페이스
- **반응형 레이아웃**: 모바일부터 데스크톱까지 최적화
- **부드러운 애니메이션**: 사용자 경험을 향상시키는 인터랙션
